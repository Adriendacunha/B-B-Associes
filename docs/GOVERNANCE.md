# 39 Collect by Codex - gouvernance projet

## Principes de pilotage

Les decisions doivent privilegier :

1. la simplicite pour le client final ;
2. la reduction des allers-retours documentaires ;
3. le gain de temps pour les collaborateurs B&B Associes ;
4. la conformite suisse, notamment LPD et protection des donnees ;
5. la rapidite de mise sur le marche du MVP.

## Donnees et conformite

Toute evolution qui touche aux documents fiscaux, aux donnees personnelles, aux droits d'acces, a la conservation ou a l'IA doit documenter :

- les donnees traitees ;
- la finalite ;
- les personnes ou roles ayant acces ;
- la duree de conservation ;
- les risques LPD ou securite ;
- les mesures de mitigation.

## Arbitrages humains requis

Les sujets suivants ne doivent pas etre traites comme de simples choix techniques :

- nom public du produit ;
- hebergement et localisation des donnees ;
- usage de l'IA sur documents fiscaux ;
- duree de conservation ;
- niveaux d'acces internes ;
- bascule eventuelle vers une validation entierement automatisee.

## Regle MVP

Si une fonctionnalite augmente la complexite sans benefice fort pour la collecte documentaire, la validation cabinet ou la reduction d'un risque, elle doit etre sortie du MVP ou transformee en option ulterieure.

## Revue hebdomadaire conseillee

Chaque revue projet doit identifier :

- ce qui a avance depuis la derniere revue ;
- ce qui bloque ;
- les risques nouveaux ou persistants ;
- les decisions a preparer ;
- les priorites de la semaine suivante.
